MC-Craft API Documentation

Basics

Every link to the MC-Craft API starts with the base URL. After that comes the section you want to use, e.g. /items, /mobs or /qr.

https://api.mc-craft.com/mobs/en
https://api.mc-craft.com = your API (base URL)
/mobs = mob database
/en = English data

What do / ? = & mean

CharacterMeaningExample
/Separates path segments/mobs/en/hostile
?Starts the first parameter?q=zombie
=Connects parameter and valuelang=en
&Connects further parameters?lang=en&q=zombie
Correct: ?text=Hello&size=512&ec=H
Only the first parameter starts with ?, every other one with &.
Wrong: ?text=Hello?size=512?ec=H

Items

The item database has an endpoint for multiple items (/items) and one for exactly one item (/item, no s).

GET /items/{language}

All items in one language.

https://api.mc-craft.com/items/en
GET /items/{language}/{category}

Only items from one specific category.

https://api.mc-craft.com/items/en/combat
buildingcolorcombat foodgamemodmaterials natureredstonespawneggs toolsutility
GET /items/{language}?q={query}

Search across all categories. Can be combined with a category: /items/{language}/{category}?q={query}.

https://api.mc-craft.com/items/en?q=diamond
GET /item/{language}/{id}

Exactly one item by its ID.

https://api.mc-craft.com/item/en/diamond
Don't know the ID? Search first with /items/en?q=diamond, then take the "id" field from the response and put it after /item/en/.
Images, textures & sounds: fields like icon, texture[].file and sounds[].file already contain full URLs (e.g. to mc-craft.com/assets/img/...) and can be used directly by bots or websites.

Mobs

Works exactly like the items API: /mobs for lists, /mob (no s) for exactly one mob.

GET /mobs/{language}

All mobs in one language.

https://api.mc-craft.com/mobs/en
GET /mobs/{language}/{category}

Only mobs from one specific category.

https://api.mc-craft.com/mobs/en/hostile
bosshostilejockeys neutralpassiveplayer unused
GET /mobs/{language}?q={query}

Search across all categories, optionally combined with /mobs/{language}/{category}?q=....

https://api.mc-craft.com/mobs/en/hostile?q=zombie
GET /mob/{language}/{id}

Exactly one mob by its ID.

https://api.mc-craft.com/mob/en/zombie
For mobs too, icon, texture[].file and sounds[].file return full, directly usable URLs.

Capes

Every known Minecraft cape (Mojang, con, physical, virtual, and more) with an image, description, and category. Unlike Items/Mobs, there is no dedicated language path segment here – the language is chosen via the lang= parameter, and there's no separate singular word.

StructureExample
All capes/capes
By language/capes?lang=en
Search/capes?q=migrator&lang=en
A single cape/capes/{id}?lang=en
https://api.mc-craft.com/capes/migrator-cape?lang=en

Heads

70+ player-head items (MHF heads of creatures, blocks, and symbols) plus logo heads, including a ready-to-use /give command right in the response. The head database has no language or category paths, only search and single lookup.

StructureExample
All heads/heads
Search/heads?q=zombie
A specific head/heads/{id}
Don't know the ID? Search first (?q=...), then take the "id" field from the response and put it after /heads/.

Skins Database

MC-Craft's curated skin gallery (hand-made themed skins like Steampunk, not player uploads) – not to be confused with a real player's actual skin via /player/{name}/skin further below.

StructureExample
All skins/skins
By language/skins?lang=en
Search/skins?q=steampunk&lang=en
A single skin/skins/{id}?lang=en

Player

Public Mojang profile data for any Minecraft account (name, UUID) plus its current skin – look it up by username or UUID, perfect for Discord bots or player profiles on your own website.

GET /player/{name-or-uuid}

Player data by name or UUID.

https://api.mc-craft.com/player/Notch
GET /player/{name}/skin

Returns the player's skin directly as an image (not JSON) – perfect for <img src="...">.

https://api.mc-craft.com/player/Notch/skin

Server

Live status for any Minecraft server – player count, MOTD, version, icon, and more – for both Java and Bedrock servers. Great for showing your own server's status on a website or in a Discord bot.

GET /server/{java|bedrock}/{address}

Live status of a Minecraft server, for both editions. Replace (server) below with your own server address.

https://api.mc-craft.com/server/java/(server)
https://api.mc-craft.com/server/bedrock/(server)
Address with a port? URL-encode the colon: example.com:25565 → example.com%3A25565.

QR Code Generator

GET /qr?text={content}

Basic principle: text is the only required parameter, everything else is optional.

Parameters

ParameterValuesMeaning
textany textQR code content (URL-encoded)
designnormal / framewithout image, or with a centered icon
size~128–2048image size in pixels
ecL M Q Herror correction, low → very high (H recommended with icons)
iconsee belowicon image, only with design=frame
iconScale~0.12–0.24icon size relative to the QR code
bghex colorbackground color
darkhex colorQR module color
finderDarkhex colorcolor of the finder frames (corners)
finderCenterhex colorcolor of the finder centers

Icon scheme (only with design=frame)

SchemeExample
item:{item-id}icon=item:diamond
mob:{mob-id}icon=mob:zombie
mob:{mob-id}:bodyicon=mob:zombie:body (full body instead of head)
heart:{filename}icon=heart:full
dialog:{filename}icon=dialog:{filename}
Hex colors need a URL-encoded #: #00ff99 → %2300ff99.

Complete example

https://api.mc-craft.com/qr?text=https%3A%2F%2Fmc-craft.com&size=768&ec=H&design=frame&icon=item:diamond&lang=en&bg=%23ffffff&dark=%23111111&finderDark=%23000000&finderCenter=%2300ff99&iconScale=0.20

Advancement Generator

GET /advancement?line1={text}&line2={text}

Generates a Minecraft advancement toast as an image. Up to 4 text lines (line1–line4) possible.

https://api.mc-craft.com/advancement?line1=Advancement%20Made!&line2=Diamonds!&icon=item:diamond

Parameters

ParameterValuesMeaning
line1–line4textup to 4 text lines
iconitem:{id} / mob:{id} / mob:{id}:bodytoast icon, same as the QR code
frameachievement advancement challenge goaladvancement type (frame shape)
styletoast-dark/light/blue/system, box-dark/gold/blue/teal/purple/nightvisual style
line1Color–line4Colorhex colortext color per line
fill / border / outlinehex colorbox fill, border and outline
backgroundtransparent solid gradientbackground type (with gradient, also set bgA/bgB)
scale~1–8image size
widthauto vanilla fixed / numberbox width
shadowtrue / falsedrop shadow on/off

Complete example

https://api.mc-craft.com/advancement?frame=challenge&style=box-gold&line1=Challenge%20Complete!&line2=Diamonds!&line3=MC-Craft&line4=%3DD&icon=item:diamond&lang=en&scale=4&width=300&background=gradient&bgA=%230f2a16&bgB=%23050520&line1Color=%23ff55ff&line2Color=%23ffffff&fill=%23121212&border=%2300ff99&outline=%23000000&shadow=true

URL Encoding

Special characters in parameters (spaces, colors, colons …) must be URL-encoded.

CharacterEncoded
Space%20
:%3A
/%2F
#%23
=%3D

Automatically with JavaScript

const text = encodeURIComponent('Getting an Upgrade');
const url = `https://api.mc-craft.com/advancement?line2=${text}`;
