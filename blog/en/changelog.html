All final changes for the official 1.1.1 release

v1.1.1 August 29, 2026

Release 1.1.1: Custom Cursor, End Poem Infobox & API Status Cleanup

New Features

  • NEW Custom diamond sword cursor across the whole site
  • NEW Info box with background facts (author, language, release date, publisher) on the End Poem page

Improvements

  • IMPROVED Animated End Portal backdrop in the End Poem viewer (drifting, pulsing effect instead of a static image)
  • IMPROVED Minecraft API Status: removed 4 permanently retired Mojang endpoints that would have shown "Unknown" forever

Bugfixes

  • FIXED End Poem page: broken nested links in the hero section fixed, which had been shifting the whole page sideways
  • FIXED End Poem page: cleaned up mixed German/English text on the speed buttons

Notes

Version 1.1.1 is a smaller polish release (custom cursor, End Poem infobox) plus cleanup work (API status, End Poem layout bug).

Version History

All previous versions of MC-Craft

v1.1.0 – Map Art Generator Expansion & Loading Animation August 29, 2026

  • NEWStructure Converter – converts structures between .schematic, .schem, .litematic, and .nbt directly in the browser
  • NEWmap.dat export in the Map Art Generator – produces a real Minecraft map file instead of a structure
  • NEWFree map size (up to 50×50 maps) and ZIP export with individual maps for large builds
  • NEWContrast control and dithering for better image quality on logos, text, and photos
  • NEWSearchable tables of every block color and the 62 official Minecraft map colors
  • NEWNew loading animation on page load, with a progress readout and the current version
  • IMPROVEDMore accurate color matching in the Map Art Generator via perceptually weighted color distance
  • IMPROVEDPreview now shows the original and result side by side for comparison
  • IMPROVEDBlock selection grouped by material category, filterable and toggleable per category
  • IMPROVEDSkin Editor promoted from Alpha to Beta
  • FIXEDTarget format in the Map Art Generator incorrectly reset to .litematic on every re-generation
  • FIXEDPreview image in the Map Art Generator sometimes rendered too large or stretched
  • FIXEDRed tones were sometimes incorrectly matched to orange blocks in color search

Version 1.1.0 significantly expanded the Map Art Generator (map.dat, ZIP export, image quality) and introduced a new loading animation.

v1.0.0 – Modern Rework & Stable Launch August 22, 2026

  • NEWA unified modern design system across all pages
  • NEWFully responsive layout for smartphones, tablets, and desktops
  • NEWImproved navigation with consistent paths and controls
  • NEWRefined German and English UI copy
  • IMPROVEDBetter spacing, typography, and contrast for readability
  • IMPROVEDImproved touch targets and focus states
  • IMPROVEDOptimized image and content behavior on small screens
  • FIXEDFixed inconsistent links to the Skin Editor
  • FIXEDStandardized version labels on all pages
  • FIXEDHardened baseline mobile navigation behavior

Version 1.0.0 was MC-Craft's consolidated modern baseline: responsive, consistent, stable, and clearly structured.
