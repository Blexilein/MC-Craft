About Skin Lookup

How our technology works

What are Minecraft skins?

Skins are textures that change the appearance of your Minecraft character. Every player can upload and customize their own skin.

Steve vs. Alex model

There are two basic models: Steve (wide arms) and Alex (slim arms). Our viewer automatically detects which model is used.

MC-Craft API

We use our own MC-Craft API (api.mc-craft.com). The website only sends player requests to our API, which centrally processes and returns UUID, player name, skin data, and model type.

Mojang Texture CDN

The actual skin texture comes from textures.minecraft.net, Mojang's official texture server. It is delivered to the browser via the MC-Craft API.

SkinView3D Renderer

The 3D viewer is based on SkinView3D, a WebGL library that renders skins in real time.

Server-side API lookup

Player and skin data are not queried directly by your browser at external profile services. Our MC-Craft API handles the lookup server-side and only returns the data the website actually needs.

Player heads

With the generated commands you can place player heads in your world. Perfect for galleries or decoration.

APIs used in detail

Service URL Usage Example
MC-Craft API https://api.mc-craft.com/player/ Retrieve player data /player/Notch
MC-Craft API (skin proxy) https://api.mc-craft.com/player/ Retrieve skin texture (source: textures.minecraft.net) /player/Notch/skin
SkinView3D /assets/JS/vendor/skinview3d.bundle.js 3D rendering Locally hosted, no external request
