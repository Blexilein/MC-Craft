About Skin Lookup

How our technology works

What are Minecraft skins?

Skins are textures that change the appearance of your Minecraft character. Every player can upload and customize their own skin.

Steve vs. Alex model

There are two basic models: Steve (wide arms) and Alex (slim arms). Our viewer automatically detects which model is used.

PlayerDB API

We use PlayerDB as a CORS-compatible proxy that retrieves UUID, player name and skin texture data from the official Mojang servers.

Mojang Texture CDN

The actual skin file comes directly from textures.minecraft.net – Mojang’s official texture server.

SkinView3D Renderer

The 3D viewer is based on SkinView3D, a WebGL library that renders skins in real time.

Mojang data, browser-compatible

Since browsers cannot call the Mojang Session Server directly (CORS), we use PlayerDB as a middleman – the skin data still comes exclusively from Mojang.

Player heads

With the generated commands you can place player heads in your world. Perfect for galleries or decoration.

APIs used in detail

Service URL Usage Example
PlayerDB API https://playerdb.co/api/player/minecraft/ Retrieve player data /api/player/minecraft/Notch
Mojang Textur-CDN https://textures.minecraft.net/ Retrieve skin images /texture/{hash}
SkinView3D /assets/JS/vendor/skinview3d.bundle.js 3D rendering Locally hosted, no external request
