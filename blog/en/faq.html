FAQ - Frequently Asked Questions

Answers to the most frequently asked questions about MC-Craft

General Questions

What is MC-Craft?

All about our platform and its goals

MC-Craft is a comprehensive platform for Minecraft players offering various tools and information. These include text converters for Minecraft formatting, detailed information on items and mobs, skin lookup functions, and server status checks. Our platform is completely free and continuously expanded.

Is MC-Craft free?

Information about costs and usage

Yes, MC-Craft is completely free! We believe all Minecraft players should have access to useful tools and information without having to pay. There are no hidden costs or subscriptions.

Do I need an account to use MC-Craft?

Information about registration

No, you do not need a user account for most functions of MC-Craft. All tools can be used immediately without registration. We do not store any personal data unless you use certain functions that require it.

Tools & Features

How does the Text Converter work?

Instructions for using the Text Converter

The Text Converter converts normal text into the Minecraft Standard Galactic Alphabet. Simply enter your desired text into the input field, and the converter immediately generates the corresponding Minecraft formatting.

Can I create colored text with the converter?

Color text and formatting options

Yes, our Color Text Converter allows you to create colored text for Minecraft. You can select different color codes and formatting options (bold, italic, strikethrough) to customize your text.

How can I look up a Minecraft skin?

Skin Lookup functionality

To look up a skin, simply enter the player's username into the search field on the Skin Lookup page. The tool then searches the Minecraft database for the skin, UUID, and any available capes.

What can I find in the Items Database?

Look up item info and properties

The Items Database lists every Minecraft item by category (building materials, tools, food, redstone, and more) with an image, ID, properties, and description. Use the search or category filters to quickly find the item you're looking for.

What does the Mobs Database show me?

Creatures, stats, and drops

The Mobs Database lists every Minecraft creature with health points, behavior, spawn conditions, and drops – sorted into categories like Passive, Neutral, Hostile, and Boss mobs.

How does the Server Status check work?

Check a Minecraft server live

Enter a Minecraft server's address and the tool shows you in real time whether the server is online, how many players are currently active, the current version, and more.

What does the Minecraft API Status page show?

Availability of the official Mojang services

This page checks the live status of the most important official Mojang/Microsoft services (e.g. login server, session server, Minecraft.net) and instantly shows you whether there are any current issues or outages.

How does the Skin Editor work?

Edit Minecraft skins directly in your browser

With the Skin Editor you can load an existing skin or start a new template and edit it pixel by pixel directly in your browser with a 3D preview – no extra software needed.

What does the Day-Night Cycle simulator do?

Visualize Minecraft's time of day

This tool visually simulates Minecraft's day-night cycle, so you can see, for example, when monsters can spawn or how long an in-game day takes in real time.

What is the End Poem page?

Minecraft's ending credits text

Here you can find the famous "End Poem" – the text that appears in the credits after defeating the Ender Dragon – to read at your own pace.

What is the Capes Database?

All Minecraft capes at a glance

The Cape Gallery shows you every known Minecraft cape – from official Mojang capes to event capes and special community capes – including an image and its origin.

What does the Minecraft version overview offer?

All releases at a glance

This page lists every Minecraft version from the earliest Alpha builds to the current release, including release date and version type (Release, Snapshot, Beta).

What is the Skin Library?

Browse skins for inspiration

The Skin Gallery contains a collection of well-known and popular Minecraft skins to browse and use as inspiration for your own skin.

What is the Beacon Color Mixer for?

Calculate beacon colors

The Beacon Color Mixer calculates which combination of stained glass you need to stack above a beacon to get exactly the light color you want.

How does the QR Code Generator work?

Create QR codes e.g. for server IPs

Enter any text or link (e.g. your server IP) and the tool instantly generates a QR code you can download – handy for quickly sharing with friends.

What does the Advancement Generator do?

Create your own advancement notifications

With the Advancement Generator you can design your own custom Minecraft advancement toast notifications and download them as an image – e.g. for videos or thumbnails.

Technical Questions

Does MC-Craft work on mobile devices?

Responsive design and mobile usage

Yes, MC-Craft is fully responsive and works on smartphones, tablets, and desktop computers. The interface automatically adapts to the screen size, so you can use all functions on the go.

Which browsers are supported?

Browser compatibility

MC-Craft supports all modern browsers, including Chrome (recommended), Brave, Firefox, Safari, and Edge. For older browsers (Internet Explorer), MC-Craft may not function correctly.
