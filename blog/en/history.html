Our Timeline

The key steps toward version 1.2.0

March 2026

The Birth

It started with one goal: deliver reliable Minecraft tools without unnecessary complexity.

  • Project kickoff and initial architecture
  • Prototypes for text and color tools
  • First internal test setup
2026

Community Growth

Community feedback helped transform a prototype into a real platform.

  • Expansion of core tools
  • Unified navigation and page structure
  • DE/EN language support integrated
  • Mobile-first improvements delivered
Version 1.0.0

Stable Release

With version 1.0.0, MC-Craft launched as a consolidated and modern platform.

  • Version labels standardized to 1.0.0
  • Design and responsiveness modernized
  • Copy and translations refined
  • Stability and quality fixes completed
Version 1.1

Expansion & Polish

At the end of August 2026, the Structure Converter arrived and existing tools were expanded and refined.

  • New tool: Structure Converter (.schematic, .schem, .litematic and .nbt)
  • Map Art Generator expanded (including map.dat and ZIP export)
  • New loading animation
  • Custom diamond-sword cursor
  • Info box on the End Poem page
Version 1.2.0

New Tools, New UI & Our Own API

In September 2026, eleven new tools, our own API, a new interface for every page and lots of data straight from Minecraft arrived.

  • 3D Skin Poser, Chibi Skin Maker and Minecraft Heads
  • Head Texture Generator, Nether Coordinate Calculator, Minecraft Command Generator, Sign Generator, Crafting Recipes, Schematic Viewer, Armor Trim Generator and Firework Generator
  • Our own MC-Craft API with public documentation
  • A new interface on all 84 pages: header, hero, navigation and footer
  • 3D models, sounds and game data for the Mobs Database, textures and sounds for the Items Database – all up to date with Minecraft 26.3
  • Many bug fixes, better accessibility and polish

What Version 1.2.0 Stands For

Version 1.2.0 builds on the consolidated 1.0 baseline: new tools, our own API, a new, consistent interface for every page and data straight from Minecraft 26.3.

New Tools

Eleven new tools – from the 3D Skin Poser to the Schematic Viewer and the Firework Generator – expand the collection.

Our Own API

The MC-Craft API is publicly documented – for bots, Discord and your own websites.

New Interface

Header, hero, navigation and footer have been redesigned and look the same on every page – from one central source.

Polish & Accessibility

Better keyboard use, fitting mouse cursors and many fixed bugs.

Questions about this development? Contact us directly by email or Discord.
