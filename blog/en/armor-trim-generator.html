Commands

For Minecraft Java 1.21.5 and later (26.x). Commands in chat need cheats or operator rights.

Good to know

  • Pick “All pieces” to apply a choice to the whole set – or a single piece to style it differently.
  • When the trim material matches the armor material (e.g. iron on iron), Minecraft uses a darker colour so the trim stays visible.
  • Drag to rotate the model, use the mouse wheel to zoom.
  • Leather armor can be dyed freely – the colour goes into the command as dyed_color.

Copying templates
