These block types don't exist in .schematic (pre-Minecraft 1.13) and were replaced with air:

    .schematic – old MCEdit/WorldEdit format (pre-1.13). Lossy: blocks with no legacy equivalent are replaced with air.

    .schem – current WorldEdit format (Sponge Schematic). Lossless for all modern block states.

    .litematic – format used by the Litematica mod. Multiple regions in one file are merged into one on import.

    .nbt – format used by Structure Blocks (vanilla Java). Lossless for all modern block states, including block entities.

    Bedrock Edition (.mcstructure) is not currently supported.
