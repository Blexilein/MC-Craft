So meldest du einen Bug

1. Discord beitreten

2. Channel finden

3. Bug beschreiben

Poste eine detaillierte Beschreibung deines Problems

4. Screenshots teilen

Häufige Fragen

Alles, was du über Bug-Reports wissen musst

Wie lange dauert eine Antwort auf Discord?

Normalerweise innerhalb von 15-60 Minuten während unserer Supportzeiten (Mo-Fr 10:00-18:00 Uhr). An Wochenenden kann es etwas länger dauern.

Was passiert nachdem ich einen Bug gemeldet habe?

1. Unser Team prüft deinen Report
2. Bug wird kategorisiert und priorisiert
3. Entwicklung zur Behebung beginnt
4. Du erhältst Updates im Discord-Channel

Kann ich mehrere Bugs auf einmal melden?

Am besten meldest du jeden Bug in einer separaten Nachricht. Das hilft uns bei der Nachverfolgung und schnelleren Behebung.

Welche Informationen sollte ich bereithalten?

• Welches Tool betroffen ist
• Genauer Fehlerbeschreibung
• Screenshots oder Videos
• Browser und Betriebssystem
• Schritte zum Reproduzieren

Weitere Fragen? Besuche unsere FAQ-Seite oder kontaktiere uns direkt.

Bereit, deinen Bug zu melden?

Je schneller du meldest, desto schneller können wir helfen! Nutze Discord für sofortige Unterstützung.
