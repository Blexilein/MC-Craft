Über Skin Lookup

Wie unsere Technologie funktioniert

Was sind Minecraft Skins?

Skins sind Texturen, die das Aussehen deines Minecraft-Charakters verändern. Jeder Spieler kann seinen eigenen Skin hochladen und anpassen.

Steve vs. Alex Modell

Es gibt zwei Grundmodelle: Steve (breite Arme) und Alex (schlanke Arme). Unser Viewer erkennt automatisch, welches Modell verwendet wird.

MC-Craft API

Wir verwenden unsere eigene MC-Craft API (api.mc-craft.com). Die Webseite sendet Spieleranfragen ausschließlich an unsere API, die UUID, Spielername, Skin-Daten und Modelltyp zentral verarbeitet und zurückliefert.

Mojang Textur-CDN

Die eigentliche Skin-Textur stammt von textures.minecraft.net, Mojangs offiziellem Texture-Server. Sie wird über die MC-Craft API an den Browser ausgeliefert.

SkinView3D Renderer

Der 3D-Viewer basiert auf SkinView3D, einer WebGL-Bibliothek, die Skins in Echtzeit rendert.

Serverseitige API-Abfrage

Spieler- und Skin-Daten werden nicht direkt vom Browser bei externen Profil-Diensten abgefragt. Unsere MC-Craft API übernimmt die Abfrage serverseitig und liefert nur die benötigten Daten an die Webseite zurück.

Spielerköpfe

Mit den generierten Befehlen kannst du Spielerköpfe in deiner Welt platzieren. Perfekt für Galerien oder Dekoration.
