MC-Craft API Dokumentation

Der komplette Link-Aufbau der MC-Craft API, einfach erklärt: Items, Mobs, Capes, Heads, Skins, Player, Server-Status, QR-Codes und Advancements – alles über eine einzige REST-API.

  • Keine Authentifizierung nötig
  • Antworten als JSON
  • Direkt von Bots & Webseiten nutzbar

Grundlagen

Jeder Link zur MC-Craft API beginnt mit der Base URL. Danach folgt der Bereich, den du benutzen möchtest, z. B. /items, /mobs oder /qr.

https://api.mc-craft.com/mobs/de
https://api.mc-craft.com = deine API (Base URL)
/mobs = Mob-Datenbank
/de = deutsche Daten

Was bedeuten / ? = &

ZeichenBedeutungBeispiel
/Trennt Teile des Pfads/mobs/de/hostile
?Startet den ersten Parameter?q=zombie
=Verbindet Parameter und Wertlang=de
&Verbindet weitere Parameter?lang=de&q=zombie
Richtig: ?text=Hallo&size=512&ec=H
Nur der erste Parameter beginnt mit ?, alle weiteren mit &.
Falsch: ?text=Hallo?size=512?ec=H

Items

Die Item-Datenbank kennt mehrere Items (/items) und genau ein Item (/item, ohne s).

GET /items/{sprache}

Alle Items einer Sprache.

https://api.mc-craft.com/items/de
GET /items/{sprache}/{kategorie}

Nur Items einer bestimmten Kategorie.

https://api.mc-craft.com/items/de/combat
buildingcolorcombat foodgamemodmaterials natureredstonespawneggs toolsutility
GET /items/{sprache}?q={suchwort}

Suche über alle Kategorien hinweg. Kann mit einer Kategorie kombiniert werden: /items/{sprache}/{kategorie}?q={suchwort}.

https://api.mc-craft.com/items/de?q=diamant
GET /item/{sprache}/{id}

Genau ein Item über seine ID.

https://api.mc-craft.com/item/de/diamond
ID unbekannt? Erst mit /items/de?q=diamant suchen, dann das Feld "id" aus der Antwort hinter /item/de/ setzen.
Bilder, Texturen & Sounds: Felder wie icon, texture[].file und sounds[].file enthalten bereits vollständige URLs (z. B. zu mc-craft.com/assets/img/...) und können direkt von Bots oder Webseiten verwendet werden.

Mobs

Funktioniert genauso wie die Items-API: /mobs für Listen, /mob (ohne s) für genau einen Mob.

GET /mobs/{sprache}

Alle Mobs einer Sprache.

https://api.mc-craft.com/mobs/de
GET /mobs/{sprache}/{kategorie}

Nur Mobs einer bestimmten Kategorie.

https://api.mc-craft.com/mobs/de/hostile
bosshostilejockeys neutralpassiveplayer unused
GET /mobs/{sprache}?q={suchwort}

Suche über alle Kategorien, optional kombinierbar mit /mobs/{sprache}/{kategorie}?q=....

https://api.mc-craft.com/mobs/de/hostile?q=zombie
GET /mob/{sprache}/{id}

Genau ein Mob über seine ID.

https://api.mc-craft.com/mob/de/zombie
Auch bei Mobs liefern icon, texture[].file und sounds[].file vollständige, direkt nutzbare URLs.

Capes

Alle bekannten Minecraft-Capes (Mojang, Cons, physische, virtuelle u. v. m.) mit Bild, Beschreibung und Kategorie. Anders als bei Items/Mobs gibt es hier kein eigenes Sprach-Pfadsegment – die Sprache wird über den Parameter lang= gewählt, und es gibt kein separates Singular-Wort.

AufbauBeispiel
Alle Capes/capes
Nach Sprache/capes?lang=de
Suchen/capes?q=migrator&lang=de
Ein einzelnes Cape/capes/{id}?lang=de
https://api.mc-craft.com/capes/migrator-cape?lang=de

Heads

Über 70 spielbare Spielerköpfe (MHF-Köpfe von Kreaturen, Blöcken und Symbolen) sowie Logo-Köpfe, inklusive fertigem /give-Befehl in der Antwort. Die Head-Datenbank hat keine Sprach- oder Kategorie-Pfade, nur Suche und Einzelabruf.

AufbauBeispiel
Alle Heads/heads
Suchen/heads?q=zombie
Ein bestimmter Head/heads/{id}
ID unbekannt? Erst suchen (?q=...), dann das Feld "id" aus der Antwort hinter /heads/ setzen.

Skins-Datenbank

Die kuratierte Skin-Galerie von MC-Craft (handgemachte Themen-Skins wie Steampunk, nicht Spieler-Uploads) – nicht zu verwechseln mit dem echten Spieler-Skin über /player/{name}/skin weiter unten.

AufbauBeispiel
Alle Skins/skins
Nach Sprache/skins?lang=de
Suchen/skins?q=steampunk&lang=de
Ein einzelner Skin/skins/{id}?lang=de

Player

Öffentliche Mojang-Profildaten zu jedem Minecraft-Account (Name, UUID) sowie dessen aktueller Skin – per Spielername oder UUID abrufbar, ideal für Discord-Bots oder Spielerprofile auf deiner Webseite.

GET /player/{name-oder-uuid}

Spielerdaten über Namen oder UUID.

https://api.mc-craft.com/player/Notch
GET /player/{name}/skin

Liefert den Skin des Spielers direkt als Bild (nicht als JSON) – ideal für <img src="...">.

https://api.mc-craft.com/player/Notch/skin

Server

Live-Status eines beliebigen Minecraft-Servers – Spieleranzahl, MOTD, Version, Icon und mehr – für sowohl Java- als auch Bedrock-Server. Ideal, um den Status eines eigenen Servers auf einer Webseite oder in einem Discord-Bot anzuzeigen.

GET /server/{java|bedrock}/{adresse}

Live-Status eines Minecraft-Servers, für beide Editionen. Ersetze (server) unten durch die eigene Server-Adresse.

https://api.mc-craft.com/server/java/(server)
https://api.mc-craft.com/server/bedrock/(server)
Adresse mit Port? Doppelpunkt URL-kodieren: example.com:25565 → example.com%3A25565.

QR-Code-Generator

GET /qr?text={inhalt}

Grundprinzip: text ist der einzige Pflicht-Parameter, alles andere ist optional.

Parameter

ParameterWerteBedeutung
textbeliebiger TextInhalt des QR-Codes (URL-kodiert)
designnormal / frameohne Bild bzw. mit Icon in der Mitte
size~128–2048Bildgröße in Pixel
ecL M Q HFehlerkorrektur, niedrig → sehr hoch (H bei Icons empfohlen)
iconsiehe untenIcon-Bild, nur mit design=frame
iconScale~0.12–0.24Größe des Icons relativ zum QR-Code
bgHex-FarbeHintergrundfarbe
darkHex-FarbeQR-Modulfarbe
finderDarkHex-FarbeFarbe der Finder-Rahmen (Ecken)
finderCenterHex-FarbeFarbe der Finder-Mitte

Icon-Schema (nur mit design=frame)

SchemaBeispiel
item:{item-id}icon=item:diamond
mob:{mob-id}icon=mob:zombie
mob:{mob-id}:bodyicon=mob:zombie:body (ganzer Körper statt Kopf)
heart:{dateiname}icon=heart:full
dialog:{dateiname}icon=dialog:{dateiname}
Hex-Farben brauchen ein URL-kodiertes #: #00ff99 → %2300ff99.

Komplettes Beispiel

https://api.mc-craft.com/qr?text=https%3A%2F%2Fmc-craft.com&size=768&ec=H&design=frame&icon=item:diamond&lang=de&bg=%23ffffff&dark=%23111111&finderDark=%23000000&finderCenter=%2300ff99&iconScale=0.20

Advancement-Generator

GET /advancement?line1={text}&line2={text}

Erzeugt einen Minecraft-Advancement-Toast als Bild. Bis zu 4 Textzeilen (line1–line4) möglich.

https://api.mc-craft.com/advancement?line1=Advancement%20Made!&line2=Diamonds!&icon=item:diamond

Parameter

ParameterWerteBedeutung
line1–line4Textbis zu 4 Textzeilen
iconitem:{id} / mob:{id} / mob:{id}:bodyIcon des Toasts, wie beim QR-Code
frameachievement advancement challenge goalAdvancement-Typ (Rahmenform)
styletoast-dark/light/blue/system, box-dark/gold/blue/teal/purple/nightoptischer Stil
line1Color–line4ColorHex-FarbeTextfarbe je Zeile
fill / border / outlineHex-FarbeBox-Füllung, -Rahmen und -Outline
backgroundtransparent solid gradientHintergrundtyp (bei gradient zusätzlich bgA/bgB)
scale~1–8Bildgröße
widthauto vanilla fixed / ZahlBoxbreite
shadowtrue / falseSchlagschatten an/aus

Komplettes Beispiel

https://api.mc-craft.com/advancement?frame=challenge&style=box-gold&line1=Challenge%20Complete!&line2=Diamanten!&line3=MC-Craft&line4=%3DD&icon=item:diamond&lang=de&scale=4&width=300&background=gradient&bgA=%230f2a16&bgB=%23050520&line1Color=%23ff55ff&line2Color=%23ffffff&fill=%23121212&border=%2300ff99&outline=%23000000&shadow=true

URL-Encoding

Sonderzeichen in Parametern (Leerzeichen, Farben, Doppelpunkte …) müssen URL-kodiert werden.

ZeichenKodiert
Leerzeichen%20
:%3A
/%2F
#%23
=%3D

Automatisch mit JavaScript

const text = encodeURIComponent('Getting an Upgrade');
const url = `https://api.mc-craft.com/advancement?line2=${text}`;
